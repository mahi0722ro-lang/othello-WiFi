# OTHELLO / LOCAL ARENA

同じWi-Fi内で2人対戦するオセロです。Node.jsサーバーを1台のPCで起動し、2台の端末からブラウザでアクセスします。

## 起動方法（Windows）

1. Node.js の LTS版をインストール: https://nodejs.org/
2. このフォルダでターミナル（コマンドプロンプト）を開く
3. 次を実行:

   ```bash
   npm install
   npm start
   ```

4. ホストPCのローカルIPv4アドレスを調べる。コマンドプロンプトで `ipconfig` を実行し、「IPv4 アドレス」（例 `192.168.1.10`）を確認。
5. ホストPCのブラウザで `http://localhost:3000` を開く。
6. もう一方の端末も同じWi-Fiにつなぎ、`http://192.168.1.10:3000` のようにホストPCのIPを使って開く。
7. 画面の「サーバーアドレス」には両方とも `ws://192.168.1.10:3000` を入力。ホストPC自身なら `ws://localhost:3000` でも可。
8. 1人目がルーム名・パスワードを決めて「ルーム作成」。2人目が同じ情報で「ルーム参加」。

## 接続できないとき

- 両方の端末が同じWi-Fiに接続されているか確認。
- Windows ファイアウォールが Node.js の受信通信をブロックしていたら、プライベートネットワークで許可。
- ルーターの「AP isolation / クライアント分離」が有効だと端末同士で通信できない場合があります。
- サーバーを起動しているPCをスリープさせない。
- ルームはサーバーのメモリ上に保存され、サーバーを止めると消えます。

## セキュリティ

これは家庭内Wi-Fi向けの簡易サンプルです。ルームパスワードは平文比較で、通信は暗号化されません。インターネットへ公開したり、重要な情報と同じパスワードを使ったりしないでください。
